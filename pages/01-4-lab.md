## 실습 A: 실행 과정을 말로 설명하기

다음 명령을 실행하기 전에 각 명령이 바꿀 내용을 예상해 적는다.

```powershell
npm install
npm run dev
npx tsc --noEmit
npm run build
```

실행 후 예상과 실제 결과를 비교한다. `npm install`은 소스 기능을 직접 실행하는 명령이 아니라 의존성을 준비한다. `npm run dev`는 종료하기 전까지 계속 실행되는 서버다. `tsc --noEmit`은 파일을 만들지 않고 검사한다. `build`는 운영 배포에 사용할 결과를 만든다.

## 실습 C: 문법 오류 추적

다음 코드는 왜 오류가 나는가?

```ts
try {
  if (ready) {
    start();
  }
}
```

JavaScript의 `try`에는 `catch` 또는 `finally`가 필요하다. 오류 위치가 마지막 `}`에 표시되어도 원인은 `try` 구조 전체다. 다음 두 방법 중 목적에 맞게 고친다.

```ts
try {
  if (ready) start();
} catch (error) {
  console.error(error);
}
```

또는 실패를 따로 처리할 필요가 없다면 `try`를 제거한다. 문법을 모르고 세미콜론만 추가하면 해결되지 않는다.
